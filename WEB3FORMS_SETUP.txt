BOYZ | THE APPLICATION
Web3Forms integration

The candidate-facing application remains entirely inside application.html.
The form submits asynchronously to Web3Forms and keeps the BOYZ visual experience.

Access key is embedded client-side because Web3Forms access keys are public keys.
Do not replace the key unless the Web3Forms form is changed.

After uploading the files to GitHub Pages:
1. Open the live application page.
2. Complete a test application with fictional data.
3. Submit it.
4. Confirm the submission arrives at the email account configured in Web3Forms.
5. Confirm the success message appears on the site.

The application should not redirect candidates to Google Forms.
