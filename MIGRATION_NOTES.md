# BOYZ — Site Migration

This build migrates the previous BEASTS website into the new BOYZ identity.

## Brand
- Primary wordmark: `boyz`
- Primary icon: the `b` from the same wordmark
- No `by MONSTERS` association
- Tone: soft luxury / it-boy / polished editorial
- Core line: `PRETTY. POPULAR. PROBLEMATIC.`

## Visual system
- Ice Blue
- Sand
- Frosted Lavender
- Silver
- White
- Dual Tone
- Black & Ice
- Typography: Ballet / Allura for the signature, Cormorant Garamond for editorial display, Inter for UI

## Content migration
- BEASTS terminology removed from active site code.
- The previous animal-centered hierarchy language was replaced where appropriate with `New Boyz`, `Boyz`, `Alphas`, and `Circle`.
- Lore and concept copy were rewritten to emphasize personality, presence, style, ambition, social influence, brotherhood, and the deliberately fresh / confident / problematic character of BOYZ.
- Existing application flow and Web3Forms integration were preserved.

## Important
The previous BEASTS ZIP remains untouched in the Library. This is a new migrated build.
